# HR Attrition Analytics Dashboard
https://hr-attrition-dashboard-hw7wtgaoyng3jnf84bexy8.streamlit.app/

An interactive dashboard that analyzes employee attrition and uses AI to generate insights and answer questions about the data.

**Live demo:** YOUR_STREAMLIT_LINK_HERE

## What it does
- Shows 5 interactive charts: overall attrition, and attrition by department, business travel, age, and education level
- Generates an AI executive summary with recommendations at the click of a button
- Includes a chat box where you can ask questions about the data in plain English

## What I did
- Explored a dataset of 1,470 employee records and calculated attrition rates across key employee groups using Pandas
- Built the charts with Plotly
- Turned the analysis into a web app with Streamlit
- Connected the OpenAI API to generate insights and power the chat
- Deployed the app on Streamlit Cloud

## Built with
Python, Pandas, Plotly, Streamlit, OpenAI API

## Why I built it
To practice turning raw HR data into insights and recommendations, the way a business analyst would for leadership.
